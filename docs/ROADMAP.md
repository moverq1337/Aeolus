# Roadmap

## Сделано

- **Lock Screen music widget** (v0.2.0): карточка Now Playing над зоной пароля
  через SkyLight-пространство уровня 400, opt-in, кнопки работают до
  аутентификации. См. docs/superpowers/specs/2026-08-15-lockscreen-widget-design.md.

## Одобрено владельцем (2026-08-15)

Медиа и остров:
- Цвет-акцент из обложки (свечение прогресса/тени острова).
- Double-tap по свёрнутому острову = play/pause.
- Waveform-визуализатор как опция (CALayer, ноль CPU).
- Превью времени при hover на прогресс-баре.
- Точная перемотка: Option + горизонтальный свайп = скраб.

Система:
- AirPods-транзиент (подключение + заряд; исследовать глубину API).
- Индикатор Low Power Mode в батарейном транзиенте.
- Режимы фокусирования (детали уточняются).
- Instant Notifications (детали уточняются).

Локскрин:
- Редизайн виджета в стиле нативного iOS-плеера (референс у владельца):
  морозное стекло, тонирование под обложку, стили/позиция.

UX:
- Чувствительность жестов + инверсия в настройках.
- Глобальные горячие клавиши (Carbon RegisterEventHotKey, без зависимостей).
- Мини-онбординг жестов при первом запуске.

Крупное:
- Виртуальный вырез на внешних мониторах.
- CLI через distributed notifications.
