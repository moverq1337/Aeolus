# Ручной чек-лист качества (перед каждым релизом)

Спека: docs/superpowers/specs/2026-08-14-aeolus-design.md (§6, §8).

## Плавность
- [ ] Instruments → Animation Hitches: раскрытие/сворачивание/транзиенты
      без хитчей > 8.3 мс на ProMotion-дисплее.
- [ ] Открытие ушей, раскрытие, закрытие — без пропусков кадров на глаз
      (запись экрана 120 fps в помощь).
- [ ] Закрытие не «переливается» за контур выреза (критическое демпфирование).

## Простой
- [ ] Ничего не играет, остров пуст: Activity Monitor → CPU ~0.0%,
      Energy Impact ~нулевой, wake-ups не растут.
- [ ] Музыка на паузе: полоски эквалайзера статичны, CPU ~0.0%.
- [ ] Low Power Mode: анимация полосок замирает.

## Сценарии
- [ ] Источники: Music, Spotify, Safari (YouTube), Chrome.
- [ ] Fullscreen-приложение: остров поверх; с настройкой Hide — скрыт.
- [ ] Mission Control, смена Spaces (трёхпальцевый свайп), Stage Manager —
      остров стационарен, без мерцания.
- [ ] Блокировка/разблокировка, сон/пробуждение — остров живой, музыка
      детектится после пробуждения (perl-процесс перезапущен).
- [ ] Клемшелл с внешним монитором: острова нет; открыли крышку — вернулся.
- [ ] Плаг/анплаг питания: транзиент 2.5 c; при раскрытом плеере — после
      сворачивания. Порог 20%/10% — по одному разу.
- [ ] Смена трека при раскрытом острове: обложка/тексты обновляются без скачков.
- [ ] AirPods подключение: громкость управляет новым устройством, иконка
      устройства меняется.
- [ ] Quit: perl-процесс адаптера умирает (`pgrep -fl mediaremote` пусто).
