# Ручной чек-лист качества (перед каждым релизом)

Спека: docs/superpowers/specs/2026-08-14-aeolus-design.md (§6, §8).

## Плавность
- [ ] Instruments → Animation Hitches: раскрытие/сворачивание/транзиенты
      без хитчей > 8.3 мс на ProMotion-дисплее.
- [ ] Открытие ушей, раскрытие, закрытие — без пропусков кадров на глаз
      (запись экрана 120 fps в помощь).
- [ ] Закрытие не «переливается» за контур выреза (критическое демпфирование).

## Простой
- [ ] Ничего не играет, остров пуст: Activity Monitor → CPU ~0.0%,
      Energy Impact ~нулевой, wake-ups не растут.
- [ ] Музыка на паузе: полоски эквалайзера статичны, CPU ~0.0%.
- [ ] Low Power Mode: анимация полосок замирает.

## Сценарии
- [ ] Источники: Music, Spotify, Safari (YouTube), Chrome, Яндекс Музыка.
- [ ] Яндекс Музыка (рваный источник, см. NowPlayingCoalescer):
      - естественная смена трека — остров НЕ схлопывается в вырез и не
        открывается заново; раскрытый плеер остаётся раскрытым;
      - next/prev — новое название никогда не появляется с исполнителем,
        альбомом, обложкой или акцентом предыдущего трека;
      - пауза 20 с и возобновление — полоса прогресса не прыгает;
      - тексты (если включены) находятся, а не остаются пустыми;
      - кнопка shuffle не показывается (источник не публикует режим);
      - перемотка: отпустил палец — полоса стоит на новом месте и НЕ отскакивает
        назад на полсекунды (источник подтверждает seek через ~530 мс);
      - пауза 20 с → возобновление → ещё пауза: полоса ни разу не прыгает
        (правило антипрыжка должно срабатывать на каждом флипе, не один раз);
      - серия из 10 next подряд (особенно через VPN — источник тогда дольше
        тянет обложку): ни разу новое название не показано с чужой обложкой.
        Диагностика: `log stream --predicate 'subsystem ==
        "io.github.moverq1337.aeolus"' --level info` — строка
        «coalescer window expired» означает, что источник не уложился в окно;
        редкая она нормальна, частая — окно подобрано мало.
- [ ] Fullscreen-приложение: остров поверх; с настройкой Hide — скрыт.
- [ ] Mission Control, смена Spaces (трёхпальцевый свайп), Stage Manager —
      остров стационарен, без мерцания.
- [ ] Блокировка/разблокировка, сон/пробуждение — остров живой, музыка
      детектится после пробуждения (perl-процесс перезапущен).
- [ ] Сон с играющей музыкой: усыпить, сменить трек на другом устройстве или
      просто продолжить — после пробуждения остров показывает ТЕКУЩИЙ трек,
      а не тот, что играл до сна (класс багов «хвост убитого адаптера»).
- [ ] Клемшелл с внешним монитором: острова нет; открыли крышку — вернулся.
- [ ] Смена разрешения (Системные настройки → Мониторы, все масштабы):
      - чёрная форма совпадает с вырезом в КАЖДОМ масштабе — не вылезает
        губой по бокам и не оголяет шов (перекрытие — доля, см. спеку §5.3);
      - остров не моргает дважды на одну смену (AppKit шлёт две нотификации);
      - режим без выреза (в списке он на 30–40pt ниже парного: 1512x945
        против 1512x982) — острова нет; вернулись к парному — остров вернулся;
      - при включённом локскрин-виджете: заблокировать после смены разрешения,
        пилюля у выреза нового размера.
- [ ] «Показать все разрешения» → самый крупный режим (3024x1964, масштаб 1:1,
      вырез 378pt): при играющей музыке уши видны, наведение раскрывает плеер
      (он обязан быть ШИРЕ выреза, иначе прячется за ним), батарейный транзиент
      показывает оба уха целиком.
- [ ] Плаг/анплаг питания: транзиент 2.5 c; при раскрытом плеере — после
      сворачивания. Порог 20%/10% — по одному разу.
- [ ] Смена трека при раскрытом острове: обложка/тексты обновляются без скачков.
- [ ] AirPods подключение: громкость управляет новым устройством, иконка
      устройства меняется.
- [ ] Quit: perl-процесс адаптера умирает (`pgrep -fl mediaremote` пусто).


## Экран блокировки (v0.2.0, только при включённом тумблере)

ВНИМАНИЕ: перед тестами включить Remote Login и проверить спасение
`pkill -x Aeolus` со второго устройства.

- [ ] Блокировка (Ctrl+Cmd+Q, крышка, засыпание дисплея): карточка по центру,
      прибита над зоной пароля (240pt от низа + offset).
- [ ] Кнопки play/pause/next управляют музыкой с локскрина; поле пароля не
      теряет фокус; клики мимо уходят системе.
- [ ] Разблокировка паролем и Touch ID: карточка исчезает без «лишней
      секунды» и без мерцания.
- [ ] Смена трека при блокировке обновляет карточку; пауза — карточка остаётся.
- [ ] Нет медиа-сессии → локскрин чист.
- [ ] Fast user switching: карточки нет в чужой сессии.
- [ ] Слайдер Raise (0…320) не заводит карточку в запретную зону.
- [ ] Тумблер выключен → ни одного приватного вызова, карточки нет.
